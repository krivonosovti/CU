# Градиентный спуск: от параболы к линейной регрессии

## 1. Что мы ищем при обучении

В задаче предсказания калорий модель получает признаки тренировки и возвращает число. Для одного признака модель имеет вид:

$$\hat y_i = w x_i + b.$$

Здесь $x_i$ — например, длительность тренировки; $y_i$ — реальные калории; $\hat y_i$ — прогноз; $w,b$ — обучаемые параметры.

Во время обучения данные $x_i,y_i$ фиксированы. Меняются веса $w,b$. Для каждого набора весов можно вычислить ошибку $J(w,b)$. Обучение — поиск весов, при которых эта ошибка мала.

Нужно различать два графика:

- **График модели:** по горизонтали признак $x$, по вертикали прогноз $\hat y$. Например, прямая «длительность → калории».
- **График функции потерь:** по горизонтали вес $w$, по вертикали ошибка $J(w)$. На этом графике градиентный спуск ищет минимум. При двух весах поверхность ошибки живёт в трёхмерном пространстве: $(w,b,J)$.

Функция потерь — то, что минимизируем при обучении. Метрика — то, чем оцениваем прогнозы. Они могут отличаться: например, обучение по MSE и оценка по RMSLE.

## 2. Аналитическое решение на простой параболе

Возьмём учебную функцию ошибки:

$$J(w) = (w-3)^2.$$

Это парабола с вершиной при $w=3$. Минимум можно найти аналитически:

$$J'(w)=2(w-3).$$

Приравняем производную к нулю:

$$2(w-3)=0 \quad\Rightarrow\quad w^*=3.$$

Вторая производная $J''(w)=2>0$, поэтому стационарная точка является строгим минимумом. Поскольку парабола выпуклая, этот минимум глобальный. Его значение $J(3)=0$.

Для произвольной функции равенство $J'(w)=0$ ещё не доказывает минимум: это может быть максимум или стационарная точка перегиба.

## 3. Что означает производная на графике

$J'(w)$ — наклон касательной к графику ошибки в точке $w$.

- Если $J'(w)>0$, небольшое движение вправо увеличивает ошибку. Для уменьшения ошибки двигаемся влево.
- Если $J'(w)<0$, небольшое движение вправо уменьшает ошибку. Двигаемся вправо.
- Если $J'(w)=0$, касательная горизонтальна. Для нашей параболы это минимум.

Производная сообщает локальное направление изменения ошибки, но сама по себе не даёт расстояния до минимума.

Геометрически один шаг выглядит так: в текущей точке определяем наклон, меняем горизонтальную координату $w$ против знака наклона, затем вычисляем новую высоту $J(w)$. Алгоритм не скользит по касательной: касательная нужна для выбора шага, а новая ошибка вычисляется по исходной функции.

## 4. Формула градиентного спуска

$$\boxed{w_{t+1}=w_t-\eta J'(w_t)}$$

- $t$ — номер итерации;
- $w_t$ — текущий вес;
- $J'(w_t)$ — производная в текущей точке;
- $\eta>0$ — learning rate, коэффициент шага.

Фактическое изменение веса равно $\Delta w=-\eta J'(w_t)$. Поэтому при постоянном $\eta$ длина шага всё равно меняется вместе с производной.

Почему стоит минус? Для малого изменения веса работает приближение:

$$J(w+\Delta w)\approx J(w)+J'(w)\Delta w.$$

Если $\Delta w=-\eta J'(w)$, то

$$J(w+\Delta w)\approx J(w)-\eta[J'(w)]^2.$$

При ненулевой производной и достаточно малом шаге ошибка уменьшается. Для слишком большого шага локальное приближение уже не гарантирует уменьшения.

## 5. Несколько шагов вручную

Для $J(w)=(w-3)^2$ выберем $w_0=0$, $\eta=0.1$.

Первый шаг:

$$J'(0)=-6,\qquad w_1=0-0.1\cdot(-6)=0.6.$$

Второй шаг:

$$J'(0.6)=-4.8,\qquad w_2=0.6-0.1\cdot(-4.8)=1.08.$$

| Итерация $t$ | Вес $w_t$ | Ошибка $J(w_t)$ | Производная $J'(w_t)$ |
|---:|---:|---:|---:|
| 0 | 0 | 9 | −6 |
| 1 | 0.6 | 5.76 | −4.8 |
| 2 | 1.08 | 3.6864 | −3.84 |
| 3 | 1.464 | 2.359296 | −3.072 |
| 4 | 1.7712 | 1.50994944 | −2.4576 |

Вес приближается к 3, ошибка — к 0. Производная становится меньше по модулю, поэтому шаги уменьшаются даже при постоянном learning rate.

Для этого примера можно вывести формулу всей последовательности:

$$w_{t+1}-3=(1-2\eta)(w_t-3).$$

Следовательно,

$$w_t=3+(1-2\eta)^t(w_0-3).$$

При $\eta=0.1$ и $w_0=0$ получаем $w_t=3-3\cdot0.8^t$.

## 6. Как learning rate влияет на сходимость

Для нашей параболы расстояние до минимума на каждом шаге умножается на $|1-2\eta|$. Если стартуем не в минимуме, сходимость требует:

$$|1-2\eta|<1 \quad\Longleftrightarrow\quad 0<\eta<1.$$

| Learning rate | Поведение для этой параболы |
|---|---|
| $0<\eta<0.5$ | Приближение без перескоков через минимум |
| $\eta=0.5$ | Попадание в минимум за один шаг |
| $0.5<\eta<1$ | Перескоки через минимум с уменьшающейся амплитудой |
| $\eta=1$ | Колебания без приближения: из 0 получается 6, затем снова 0 |
| $\eta>1$ | Расходимость, если начальная точка не является минимумом |

Эти границы относятся именно к $J(w)=(w-3)^2$. У другой функции масштаб производной и допустимый шаг будут другими. Даже умножение функции потерь на константу изменяет подходящий learning rate, хотя положение минимума сохраняется.

## 7. Несколько параметров: градиент

Для вектора параметров $\theta=(w,b)$ производную заменяет градиент:

$$\nabla J(\theta)=
\begin{pmatrix}
\frac{\partial J}{\partial w}\\
\frac{\partial J}{\partial b}
\end{pmatrix}.$$

Каждая частная производная показывает изменение ошибки при изменении одного параметра и фиксации остальных. В евклидовой геометрии градиент направлен в сторону самого быстрого локального роста функции, а минус градиент — в сторону самого быстрого локального убывания.

Обновление:

$$\boxed{\theta_{t+1}=\theta_t-\eta\nabla J(\theta_t)}.$$

Обе компоненты градиента вычисляются в одной и той же старой точке, затем все параметры обновляются одновременно.

Для двух параметров можно рисовать линии уровня: на каждой линии ошибка одинакова. Антиградиент перпендикулярен гладкой линии уровня в точке с ненулевым градиентом и направлен к меньшим значениям. На вытянутой поверхности шаги могут идти зигзагом — одна из причин масштабировать признаки.

## 8. Вывод градиента для линейной регрессии

Обозначим ошибку прогноза объекта через $r_i=wx_i+b-y_i$. Возьмём **половину MSE**:

$$J(w,b)=\frac{1}{2n}\sum_{i=1}^{n}(wx_i+b-y_i)^2.$$

Коэффициент $1/2$ удобен: он сокращается с двойкой при дифференцировании квадрата.

По правилу производной сложной функции:

$$\frac{\partial J}{\partial w}
=\frac{1}{2n}\sum_i 2(wx_i+b-y_i)x_i
=\frac{1}{n}\sum_i r_i x_i,$$

$$\frac{\partial J}{\partial b}
=\frac{1}{2n}\sum_i 2(wx_i+b-y_i)
=\frac{1}{n}\sum_i r_i.$$

Шаг обучения:

$$w_{t+1}=w_t-\eta\frac1n\sum_i(w_tx_i+b_t-y_i)x_i,$$

$$b_{t+1}=b_t-\eta\frac1n\sum_i(w_tx_i+b_t-y_i).$$

Например, если модель в среднем завышает прогноз, средняя ошибка $r_i$ положительна. Тогда обновление уменьшает $b$ и сдвигает прогнозы вниз.

Для обычной MSE без $1/2$ обе формулы градиента дополнительно умножаются на 2.

Для связи с конкретными данными возьмём искусственный пример: длительности $x=(1,2,3)$ и калории $y=(10,20,30)$. Пока зафиксируем $b=0$, то есть будем обучать только $w$:

$$J(w)=\frac16\left[(w-10)^2+(2w-20)^2+(3w-30)^2\right]
=\frac73(w-10)^2.$$

Получилась та же парабола ошибки, но с другим центром и масштабом. Производная $J'(w)=\frac{14}{3}(w-10)$, поэтому аналитическое решение — $w^*=10$. Градиентный спуск с $w_0=0$ и $\eta=0.1$ первым шагом даст $w_1=14/3\approx4.667$, а последующими будет приближаться к 10. Это учебные числа, не наблюдения из датасета домашних заданий.

## 9. Матричная запись и аналитическое решение

Добавим в $X$ первый столбец единиц для свободного члена. Пусть $X$ имеет размер $n\times(p+1)$, а $\theta=(b,w_1,\ldots,w_p)$ — вектор размера $p+1$.

$$\hat y=X\theta,\qquad r=X\theta-y.$$

Для половины MSE:

$$J(\theta)=\frac1{2n}\|X\theta-y\|_2^2,$$

$$\boxed{\nabla J(\theta)=\frac1nX^\top(X\theta-y)}.$$

Размерности: $X^\top$ — $(p+1)\times n$, остатки — вектор длины $n$, результат — вектор длины $p+1$, то есть по одному градиенту на каждый вес.

Градиентный спуск:

$$\theta_{t+1}=\theta_t-\eta\frac1nX^\top(X\theta_t-y).$$

Для аналитического решения приравниваем градиент к нулю:

$$X^\top(X\theta-y)=0,$$

$$X^\top X\theta=X^\top y.$$

Это **нормальные уравнения**. Если столбцы $X$ линейно независимы, то

$$\boxed{\theta^*=(X^\top X)^{-1}X^\top y}.$$

Вычислять обратную матрицу явно на практике обычно не стоит: задачу наименьших квадратов решают численно, например через QR или SVD. При линейно зависимых столбцах минимум может иметь несколько наборов весов; псевдообратная матрица даёт решение с минимальной евклидовой нормой.

Таким образом, обычная линейная регрессия допускает прямое решение системы. Градиентный спуск получает приближение итерациями и применим также к задачам, для которых простой формулы решения нет.

При фиксированном преобразовании признаков, в том числе добавлении полиномов, MSE линейной модели остаётся выпуклой по весам. Полиномы усложняют зависимость от исходных признаков, но не делают её нелинейной по коэффициентам.

## 10. Связь с задачей 8: L1-регуляризация

В домашней работе минимизируется не только ошибка, но и штраф:

$$J(\theta)=\frac1{2n}\|X\theta-y\|_2^2+\alpha\sum_{j=1}^{p}|\theta_j|.$$

Свободный член $\theta_0=b$ не штрафуется.

При ненулевом весе производная $|\theta_j|$ равна $\operatorname{sign}(\theta_j)$. В нуле обычной производной нет: для задания выбираем субградиент 0.

$$g(\theta)=\frac1nX^\top(X\theta-y)
+\alpha\begin{pmatrix}0\\\operatorname{sign}(\theta_1)\\\vdots\\\operatorname{sign}(\theta_p)\end{pmatrix}.$$

Обновление: $\theta_{t+1}=\theta_t-\eta g(\theta_t)$.

Не путать параметры: $\eta$ (в коде `lr`) управляет шагом оптимизации; $\alpha$ — силой регуляризации и меняет саму задачу оптимизации. Формула обычного МНК из предыдущего раздела не решает задачу с L1-штрафом.

С постоянным шагом субградиентный метод может колебаться около минимума. В задаче 8 сначала сравнивают значение целевой функции с Lasso, а RMSLE рассматривают отдельно. Меньшая MSE со штрафом не гарантирует меньшую RMSLE.

## 11. Минимальный пример кода

```python
def loss(w):
    return (w - 3) ** 2

def grad(w):
    return 2 * (w - 3)

w = 0.0
lr = 0.1

for step in range(100):
    gradient = grad(w)
    if abs(gradient) < 1e-6:
        break
    w = w - lr * gradient

print(w)        # примерно 3
print(loss(w))  # примерно 0
```

В этом примере градиент вычисляется аналитически по формуле, но минимум ищется численно итерациями. «Аналитическая производная» и «аналитическое решение задачи оптимизации» — разные вещи.

Для гладкой задачи возможные критерии остановки: малый градиент, малое изменение весов или ошибки, лимит итераций. Ни один технический критерий сам по себе не означает, что качество на новых данных достаточно хорошее.

## 12. Batch, stochastic и mini-batch

- **Batch gradient descent:** один шаг использует градиент по всей обучающей выборке. Именно такой вариант записан выше и нужен в задаче 8.
- **Stochastic gradient descent (SGD):** один шаг использует один объект; направление получается шумным.
- **Mini-batch gradient descent:** один шаг использует небольшую группу объектов, например 32 или 128.

Для mini-batch одна эпоха означает проход по всей обучающей выборке, а одна итерация — одно обновление весов. В полном batch-спуске одно обновление уже использует все объекты.

## 13. Проверка понимания

1. Если $J'(w)=-4$ и $\eta=0.1$, вес увеличится или уменьшится?
2. Если learning rate постоянный, постоянна ли длина шага?
3. Для $J(w)=(w-3)^2$, $w_0=0$, $\eta=1$ чему равны $w_1,w_2$?
4. Почему уменьшение обучающей MSE не гарантирует уменьшения RMSLE на val?

Ответы: 1) увеличится на 0.4; 2) нет, шаг зависит от градиента; 3) 6 и 0 — колебания; 4) это разные функции, к тому же обучение и оценка выполняются на разных данных.
